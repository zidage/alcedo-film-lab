# Results

Measurement results of the prototypes under `scripts/poc/`. Each step has one directory. The
report of the step explains the values; the script README states the commands that make them.

Only the text results (JSON, Markdown) are committed. Plots are written to `plots/` in the same
directories but are not committed (`*.png` is in `.gitignore`). Some plots contain renders of
manufacturer charts, which must not be published.
